# Master Japanese Vocabulary Curriculum (50 Decks / 3 Tiers)

* **Writing Standard:** Kana (Hiragana/Katakana) + Romaji front; English back. Zero Kanji.
* **Information Standard:** Every card includes `{?}` context/usage notes plus 3 natural kana/romaji/English sentence examples.
* **Deck Size Standard:** Calibrated strictly between 20 and 35 cards per deck to avoid cognitive fatigue while fitting micro-learning sessions.
